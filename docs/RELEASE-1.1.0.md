# TriliumNext Flux v1.1.0

## 新增 · # 快速录入

在任务文本中输入 `#`，弹出候选菜单，一键补全：

- 日期：`today` / `tomorrow` / `next`（周末、下周一、+7 天、月底、下月初…）
- 重复：`#repeat:1w`，输入 `:N` 自定义间隔，可选 `:start` / `:end` / `:actual` 锚点
- 打卡：`#habit:5`，输入 `:N` 自定义每周天数，可选每天次数
- 计时：`#timer:25`，可续写休息分钟与自定义阶段名
- `↑` `↓` 选择，`Enter` / `Tab` 插入，或直接点击

可在 **设置 → 基础设置 → # 快速录入** 中随时关闭。

## 其他更新

- 标签固定为 `#repeat` / `#habit` / `#timer`，配置相应简化
- `#` 候选提示文案精简，更简洁
- 设置界面新增「# 快速录入」开关

# TriliumNext Flux v1.1.0 (English)

## New · Quick insert (#)

Type `#` in task text to pop up a candidate menu for one-click tag completion:

- Dates: `today` / `tomorrow` / `next` (weekend, next Mon, +7 days, month end, next 1st…)
- Repeat: `#repeat:1w`; type `:N` for custom interval, optional `:start` / `:end` / `:actual` anchors
- Habit: `#habit:5`; type `:N` for custom days/week, optional times per day
- Timer: `#timer:25`; extend with rest minutes and custom phase names
- `↑` `↓` to select, `Enter` / `Tab` to insert, or click

Turn it off anytime under **Settings → General → Quick insert**.

## Other changes

- Tags fixed to `#repeat` / `#habit` / `#timer`, config simplified
- Slimmed-down `#` candidate hints
- New "Quick insert" toggle in settings
